# SpendWise – Expense & Savings Tracker
Web Technology (ICT3131) Mini Project · Node.js + Express + SQLite + Bootstrap 5 + Chart.js

## Run
    npm install
    npm start
Open http://localhost:3000

## Features
1. Register / Login / Logout (bcrypt + sessions)
2. Add, edit, delete income/expense transactions
3. Filter transactions by category, type, date range
4. Dashboard totals (income, expenses, balance)
5. Charts: spending by category, monthly income vs expenses
6. Monthly budgets with progress bars and over-budget warnings
7. CSV export of all transactions
